2. Data Google yang diakses dan tujuannya

Selepas pemilik memberi kebenaran (OAuth consent), aplikasi boleh mengakses perkara berikut:

Perkhidmatan GoogleTujuan
GmailMembaca dan menghantar emel milik pemilik untuk urusan automasi dan laporan (cth. ringkasan masuk, notifikasi).
Google DriveMembaca dan menyimpan fail kerja (dokumen, gambar menu, fail sokongan) dalam Drive pemilik.

Data ini digunakan semata-mata untuk menjalankan automasi dan laporan pemilik sendiri. Ia tidak digunakan untuk pengiklanan, tidak diprofilkan, dan tidak dijual. Penggunaan data Google oleh aplikasi ini terhad kepada keperluan membekalkan ciri yang dinyatakan di atas (selaras dengan Google API Services User Data Policy, termasuk keperluan Limited Use).

3. Di mana data disimpan

Aplikasi berjalan pada PC peribadi pemilik (Windows 11). Token kebenaran OAuth dan data kerja disimpan pada cakera tempatan PC itu, di bawah folder %LOCALAPPDATA%\hermes. Tiada salinan disimpan pada pelayan lain kecuali perkhidmatan Google sendiri (Gmail, Drive, Sheets, Calendar, Search Console) yang mana data itu memang berasal. Data dihantar ke perkhidmatan Google melalui sambungan HTTPS sahaja.

4. Perkongsian dengan pihak ketiga

Tiada perkongsian data Google pemilik dengan mana-mana pihak ketiga. Tiada data dijual, disewakan, atau dipindahkan kepada broker data, pengiklan, atau mana-mana organisasi lain.

5. Tempoh simpanan data

  • Token kebenaran OAuth disimpan pada PC pemilik selagi akses automasi diperlukan, dan boleh ditarik atau dipadam pada bila-bila masa.
  • Data kerja (contoh: rekod stok, laporan) disimpan selagi ia berguna untuk operasi KOFFIE, kemudian dipadam oleh pemilik.
  • Pemilik boleh membatalkan akses aplikasi pada bila-bila masa di myaccount.google.com/permissions. Selepas pembatalan, aplikasi tidak lagi boleh mengakses akaun Google tersebut.
